# Wlogout (public copy)

These four buttons use the documented native `text` property instead of PNG icons
whose copyright holder could not be established. Button actions and hotkeys match
the original configuration; only the labels and their CSS have been adapted.

To restore the original appearance privately, you may use your locally installed
icons. Do not redistribute those files without checking their licenses.

Upstream wlogout documentation: https://github.com/ArtsyMacaw/wlogout
