# Отчёт об аудите — 2026-11-05

Источник: `arch-dotfiles-audit.tar.gz` (67 файлов, 22 каталога, 918101 байт
регулярных файлов). Только статическая проверка; исходный Arch не запускался
в среде проверки, корректность отображения визуально не подтверждена.

## Найдено

1. Hyprland: современный `hyprland.lua`, автозапуск Waybar, Waypaper,
   Hyprsunset, SwayNC, clipboard watcher и hyprpolkitagent.
2. Активные вызовы Rofi: `style-8.rasi` (Super+Space и Super+R),
   `config.rasi` (окна через `rofi -show window`).
3. SDDM: скопированы QML-файлы темы, настройки и пользовательский
   `theme.conf.user`; исключены необязательные примерные оформления.
4. Wlogout: четыре PNG-иконки были в исходном архиве, но исключены из публичной копии из-за неподтверждённой лицензии.
5. GTK: `Materia-dark` указана активной; `Dracula-pink-accent` лишь
   обнаружена на компьютере, файлы темы в архив не переданы.

## Исправлено в предварительной копии, оригинал не менялся

- `Waybar`: путь `/home/dev/...` заменён на `$HOME/...`.
- `Waybar`: датчик Intel CPU привязан по штатному имени `coretemp`.
- `Wlogout`: неизвестные PNG удалены, в layout установлены встроенные текстовые надписи; CSS очищен от ссылок на иконки. Работу/расположение нужно проверить на реальном ПК.
- `Waypaper`: stylesheet теперь `~/.config/waypaper/style.css`.

## Не включено и не доказано

- Физические обои из `~/Pictures`, в том числе `wallhaven-n6y9zl.jpg`.
- Папки `Notwaita-Black` и `Dracula-pink-accent` теперь включены
  из отдельно переданного `dotfiles-themes.tar.gz` (647 обычных файлов,
  111 внутренних символических ссылок). Содержимое и исходные имена сохранены.
- Отсутствуют `Bibata-Modern-Ice`, системная `Materia-dark`, Nerd Fonts.
- Полный список установленных транзитивных зависимостей `pacman -Qq`, версии пакетов и проверка их доступности на новом ПК.
- Списки явно установленных пакетов уже получены: 129 официальных и 11 сторонних.
- Прочие конфиги вне архива, системные user services и возможные
  изменения программ за пределами `~/.config`.
- Дополнительные скриншоты (галерея Waypaper уже включена).
- Исходные PNG-иконки Wlogout исключены из публичной версии, поскольку их происхождение не подтверждено.

## Аудит дополнительного архива `dotfiles-themes.tar.gz`

- Только каталоги `themes/Dracula-pink-accent`, `icons/Notwaita-Black`,
  `icons/default`; отклоняющихся абсолютных путей и `../` нет.
- 111 символических ссылок относительны и остаются внутри включённых тем.
- В теме Dracula сохранены собственные README и полный текст GPL-3.0.
- Курсор Notwaita содержит отметку об источнике `@ful1e5`, информация о
  лицензии/атрибуции вынесена в `LICENSES/notwaita-cursor-NOTICE.md`.
- Наличие `Dracula-pink-accent` на диске **не подтверждает её активность**:
  переданные GTK-конфиги выбирают `Materia-dark`.

## Статические проверки безопасности

- Не обнаружены ключи вида PEM/OpenSSH, GitHub PAT или типичные API-токены
  в переданном наборе (проверка по шаблонам; это не гарантия безопасности).
- Авторские email в некоторых Cava shader заголовках относятся к атрибуции,
  а не к пользовательским аккаунтам.
- Публичная загрузка **не производилась**.
